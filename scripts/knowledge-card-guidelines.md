# 知识卡编写规范

所有原有及后续新增知识点均遵循用户于 2026-09-18 指定的格式：

- 卡面直接显示一段清楚易懂、重点完整的讲解，包括必要的定义、条件、公式、单位及容易混淆的地方；不要把讲解收起，也不要以原文摘录替代讲解。
- 只有需要图示时才配图。截图来自课本，只保留相关图形、箭头、坐标、必要标签及简短图注；不可使用整页文字截图代替知识卡。
- 原文摘录和来源页码保留在可展开的来源栏；图示保留原始文件、页码及裁切范围。
- 所有知识点按课本章、页及页内出现位置排序，新卡插回对应位置。跨页合并卡按最先出现的内容定位。
- 中英文版本采用同一课本顺序；稳定 sequence ID 和题目关联保持不变，章节显示编号随顺序生成。
- 讲解不能替代公式显示。`card_summary` 后仍独立显示完整的 `formula_latex` 和符号说明；行内公式使用 `\( ... \)`，上下标、分式及根号交给公式排版器处理。
- 原有卡的修订标题和讲解分别保存在 `card_title`、`card_summary`；图示采用 `review_figures`。保留原始 `content`、公式及来源资料以便追溯。英文入口的标题、讲解、公式说明、图注及卡片控件全部使用英文；中文入口保持中文。课本原文保留其原语言。重新生成数据后须应用英文卡片修订并通过英文完整性检查。
- 更新后检查讲解完整性、公式解析、图示来源与边界、全库顺序，并在桌面和手机尺寸检查页面及图片放大。
- 同章相邻、主题相关且共用插图的知识点可组成一张大卡，内部分小节；相同讲解不重复，完整公式和原有编号均保留，共用图片只显示一次。不跨章节、不跳过中间知识点，统摄性定律仍独立。仅图片相同、主题不同的内容不硬合并。
- 图片文件与页码、课本原文依据统一收进整张卡片最底部的“课本来源”折叠栏，默认隐藏；图片下只保留解释性图注。

全库 410 个知识点均采用新版格式，包括逐项修订的 365 张原有卡和之前整理的 45 张新增卡。本轮另裁切 30 幅课本示意图；必要时复用现有图示。


- 知识点之间不建立关联，不显示“相关知识”链接，也不借其他知识点推导延伸题目。保留知识点自身与真题的直接／背景关联，以及共用插图的大卡分节排版。

- 同章内中英文标题和讲解均完全相同的重复条目，按审核清单合并为一张知识卡，定位在最早出现处；汇集所有公式、图示、来源和真题，保留稳定编号与跳转锚点。定义／公式即使原分类不同也不重复显示同段讲解；统摄性定律只与自身重复条目合并，不与其他主题混合。相近但不同的概念不按文字相似度自动合并。
