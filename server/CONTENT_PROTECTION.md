# DDPhysics 内容访问与保护

当前规则更新于 2026-10-12，仅在本地完成。会员限制已恢复：详解、非必修一关联、问老师和详解打印需有效会员，必修一关联与推荐继续免费。会员开通／暂停、付款审核及通知恢复，使用既有数据；本地不发送真实邮件。章节 PDF 恢复原有关闭规则。学生周报保留原时间及失败重试，生成／发送重试按当前会员筛选，非会员保留必修一推荐。

## 原有暴露位置与处理

| 位置 | 原有情况 | 本次处理 |
| --- | --- | --- |
| `text-papers/{year}-{language}.json` | 每次返回整年题目；会员可以取整年详细解析 | 旧地址返回 404；改用单题接口 |
| `assets/textbook-examples/{language}/{chapter}.json` | 公开整章例题、解答、Think about；包含来源信息 | 整包不再公开，阅读器按单题获取展示字段 |
| `assets/textbook-exercises/{language}/{chapter}.json` | 一次返回整章；会员获得全部详细思路 | 单题免费读取，保留限流 |
| 两类课本内容的 `index-*.json` | 完整目录、搜索摘要和知识点关联随索引下发 | 旧地址关闭；新目录仅含分册/章节导航、当前章最多 50 个题号，无解析、搜索全文或关联映射 |
| `/api/premium/network` | 会员可以一次取得全部真题关联 | 返回 410；替换为单题知识点、每页最多 50 个关联题 |
| `src/lib/textbook-example-knowledge.json` | 完整例题关系编入浏览器代码 | 取消前端导入，浏览器导航仅保留题目身份；原文件保留作服务器导入源 |
| `src/lib/question-search-loader.js` | 搜索会预加载历年真题与所有课本章节 | 浏览器只提交查询，后端返回分页摘要 |
| 原 `question-search.js`、`search-concepts.js`、`profile-review.js`、`mistake-analysis.js` | 搜索评分、概念匹配及推荐规则在前端执行 | 算法移入 `server/`；旧源码模块仅作测试兼容入口，并禁止通过 HTTP 读取 |
| `vite.config.js` | 原始题库、解析、关系文件与配图复制到 `dist`，其他静态托管方式可能绕开权限中间件 | 从公开构建移除题库原包、关系、题目配图与下载文件；服务器代理文件 |
| `site-data.js`、`statistics-data.js`、`textbook-data.js` | 启动数据包含答案、关联列表或编辑审核元数据 | 生成公开版本，去除答案、完整关联和内部编辑策略；保留导航与原有公开知识卡展示内容 |

现有 Question DNA 来自此前整理的本地 JSON，原本未发现其被当前网站直接加载。现在将其导入私有数据库，并阻断普通用户获取完整内部标注；没有重新生成标注，也没有将未经独立核验的标注当作已核验结论。

## 服务端边界

沿用 Node HTTP 服务、现有 SQLite、登录 Cookie 和管理员角色，不增加外部数据库或限流基础设施。

- `protected_content`：中英文各 2,468 条，分别是 1,116 道真题、979 道课本习题、373 道例题。
- `protected_dna`：中英文各 1,116 条。`DSE_QDNA_DIR` 指向包含 `中文版/json/QDNA.json` 和 `英文版/json/QDNA.json` 的私有输入目录。本地预览默认使用本次项目已有 `output/qdna-20261008` 存档。其他运行环境应显式配置该路径。
- 当前本地数据库位于 `.local-membership-preview/students.sqlite`。不提供数据库网络端口或浏览器直连；数据库、管理密钥、点开头目录、服务端源码及内部标注地址由 HTTP 边界拒绝。仍需保管本机账号、文件 ACL 和备份。
- 题库源 JSON、原图继续保存在项目中供服务器导入/代理，它们不在 `dist`。不能将整个源项目作为静态站点公开。
- 会员权限来自真实会话和服务端当前期限／暂停状态，不接受伪造 userId 或 active。管理员拥有独立权限；普通、到期、暂停账号仅保留试读及必修一免费关联／推荐。
- 题干、官方标答、课本答案和例题保留原公开规则；原创详解及非必修一关联需会员。公开知识卡保持，章节 PDF 地址恢复关闭规则。
- 内容与受控文件响应使用 `private, no-store` 和 `Vary: Cookie`；未知文件、旧 JSON 整包、编码绕过路径及禁止的 PDF 地址不能落回静态服务。
- 详解、课本解答及思考题答案附加低干扰 `DDPhysics · U-…` 标识。追踪编号由服务端 HMAC 生成，不包含邮箱或手机号；游客使用 Preview。轮换管理密钥会改变编号。

## 接口和返回范围

所有内容接口使用 GET，拒绝未知或重复参数。搜索查询最长 200 字；分页 `limit` 为 1–50，`offset` 为 0–10000。

| 接口 | 内容与权限 |
| --- | --- |
| `/api/content/question?id=…&language=…` | 单题题干、答案及该会话有权读取的解析；不返回原始来源记录或 DNA |
| `/api/content/directory?source=…&id=…` | 分册/章节导航及当前章题号；支持 `chapter`、`offset`、`limit`；不选择章节时只有导航 |
| `/api/content/search?q=…` | 默认 30 条、最多 50 条摘要；没有完整解析、网络、匹配评分或内部查询表示 |
| `/api/content/links?id=…` | 当前题目的展示知识点及必要背景知识点，不含权重、证据或隐藏标注 |
| `/api/content/related?points=…` | 按会员及必修一免费规则返回关联题分页；一次最多 12 个知识点、最多 50 条结果，没有完整网络 |
| `/api/content/recommendations?batch=…` | 兼容入口，现使用 QDNA 引擎：最多 8 个未标记新题与 3 个错题复习，返回这些结果的分数与理由；不返回候选网络 |
| `/api/content/mistake-summary` | 会话用户自己的章节汇总与最多 3 项复习建议；可按单个知识点筛选本人的错题身份，无全库映射 |
| `/api/content/report?year=…&page=…` | 原试读范围内的一页官方报告 |
| `/api/admin/content/dna?id=…&language=…` | 只有管理员可按单题读取原始 DNA；普通学生即使是会员也被拒绝 |

题目／解析配图沿用原 URL，受控文件代理查验资源登记、是否仅出现在会员解析中及当前会员状态，同时保留下载／配图限流。原卷 PDF 保持原公开下载规则，但经过下载限流；原先关闭的整本知识 PDF 不重新开放。错题打印每次最多选择 30 道，逐题获得授权内容，不提供完整解析导出入口。

目前没有独立 AI 调用，也没有发现 OpenAI/Anthropic 调用代码。问老师是原有人工回复流程。本次没有新增 AI 接口或模型密钥，后续已按用户明确提供的《DDPhysics_QDNA_开发Prompt》将个性化推荐切换为确定性 QDNA 算法，详见 `QDNA_LEARNING.md`。

## 可调限流

集中配置：`server/content-limits.mjs`，环境变量示例在 `.env.example`。修改后重启服务。

| 变量 | 默认值 | 范围 |
| --- | ---: | --- |
| `DSE_LIMIT_DETAIL` | 90 | 单题/报告读取，每分钟 |
| `DSE_LIMIT_SEARCH` | 40 | 搜索，每分钟 |
| `DSE_LIMIT_LINKS` | 120 | 知识关联/个人复习汇总，每分钟 |
| `DSE_LIMIT_SIMILAR` | 30 | 推荐，每分钟 |
| `DSE_LIMIT_DOWNLOAD` | 12 | 原卷文件下载，每分钟 |
| `DSE_LIMIT_IMAGE` | 600 | 配图，每分钟 |
| `DSE_LIMIT_DIRECTORY` | 60 | 目录，每分钟 |
| `DSE_LIMIT_DISTINCT_HOUR` | 300 | 每小时读取不同题目的数量 |

账号分别计数；登录请求另有同 IP 的宽松总量上限，为该类账号分钟阈值的 40 倍。游客按 IP 计数。这样为同校、同家庭用户留出余量，同时限制一个账号换 IP 遍历。配图阈值高于题目阈值，允许长题多图与 30 题打印。

超出分钟限额后按 30、60、120 秒逐步冷却，最长 15 分钟；每小时新题限额随时间窗口释放。响应为 429，带 `Retry-After`。状态存在 SQLite，重启不会清空限制；没有永久封号逻辑。

本地服务直接使用 socket IP，不信任客户端自行填写的转发头。未来部署到反向代理后，应按生产拓扑只信任已知代理，避免所有游客被当作同一 IP；账号额度仍由真实会话分开计算。当前阈值是首版保守起点，需依据真实课堂使用和误限反馈调整。

## 仍有的限制与发布约束

学生已被授权看到的内容仍可截图、手抄、复制或通过低速请求积累；水印只是来源追踪辅助，可被裁掉。多个账号/IP 协作仍可能规避首版限流。没有禁用右键、选字或依赖混淆来保护内容。

公开知识卡、导航、题频汇总和试读内容仍可读取；当前保护的是题目完整原始数据包、内部 DNA 与推荐计算，而不是将已公开的教学知识变成秘密。

本地 JSON 存档、源目录和数据库仍需操作系统权限及备份管理。本次没有进行全盘凭据扫描、Git 历史泄漏清理或云数据库权限审计，也不能证明从未发生过历史泄漏。

尚未发布。未来收到明确上线指令后，必须把内容接口与文件代理接入生产安全服务，配置私有数据/DNA 路径和可信代理，保留生产身份验证、来源与代理安全、付款流程和学习邮件安排；清理旧 CDN/静态公开资源并重新检查线上直链。不能将本地预览服务、测试账号数据库或源目录整体覆盖生产。

## 后续 QDNA 功能的明确边界（同日更新）

最新开发文档要求展示“当前知识点对应题目的权重”，并要求推荐结果包含 `recommendation_score`。因此这两个字段是获授权的、有界功能返回值，不再属于完全隐藏的范围。新增 `/api/learning/dashboard` 与 `/api/learning/knowledge` 只读当前登录用户自己的统计，按最多 50 条分页、共享推荐限流；推荐固定最多 8 个新题和 3 个错题。普通用户仍不能得到完整 DNA、evidence、reasoning_steps 或全库映射包；标注和计算保留在服务器。管理员查看任意学生和完整单题 DNA 的权限保持不变。

学生自己看到的逐点权重和少量推荐分数仍可能被逐次收集，限流只能提高批量获取成本，不能承诺完全不可复制。弱点知识画像保留；关联和推荐按会员及必修一试读规则处理，内部分析字段不完整返回学生。

2026-10-12 追加恢复会员：必修一智能推荐免费，其他章节为有效会员专属；过期及暂停按非会员处理，发送及重试周报再次按当前会员状态筛选。
